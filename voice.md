# Voice

Default voice for all skills in this repository. A skill can override this in its own `SKILL.md`.

## Rules

- Concise and clear.
- Understandable by business and tech alike.
- No jargon. If a technical term is needed, define it in plain words.
- Short sentences. One idea per sentence.
- Use the formats and identifiers given in each skill's templates exactly.
- No filler. No hedging. State what is known; flag what is assumed.
