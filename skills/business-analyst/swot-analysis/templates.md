# Templates — SWOT Analysis

## Rules

- Strengths / Weaknesses = internal. Opportunities / Threats = external.
- One short sentence per entry. Specific, evidence-based.
- 3–7 entries per quadrant. Do not pad a thin input.
- Every entry must be actionable or informative for a decision.

## Output skeleton

```markdown
# [Subject] — SWOT Analysis
Date: [date]

| **Strengths** | **Weaknesses** |
| --- | --- |
| S1, S2, S3 (see detail) | W1, W2 (see detail) |
| **Opportunities** | **Threats** |
| O1, O2 (see detail) | T1, T2, T3 (see detail) |

## Strengths
- S1: ...
- S2: ...

## Weaknesses
- W1: ...

## Opportunities
- O1: ...

## Threats
- T1: ...

## So what
- [2–3 lines on implications for action]
```
