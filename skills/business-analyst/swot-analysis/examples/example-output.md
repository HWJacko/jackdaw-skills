# New Website rebuild — SWOT Analysis
Date: 2026-11-19

| **Strengths** | **Weaknesses** |
| --- | --- |
| S1–S3 (see detail) | W1–W2 (see detail) |
| **Opportunities** | **Threats** |
| O1–O2 (see detail) | T1–T2 (see detail) |

## Strengths
- S1: Existing content is already audited and structured for migration
- S2: CMS chosen matches the editors' current skills — no retraining
- S3: Hosting contract already covers the new stack

## Weaknesses
- W1: No in-house frontend capacity after March
- W2: Analytics tagging from the old site is undocumented

## Opportunities
- O1: New search platform procurement opens in Q1 — align the rebuild with it
- O2: Competitor sites have poor mobile performance; a fast site differentiates

## Threats
- T1: CMS vendor roadmap uncertain after acquisition
- T2: Rebuild competes with the payments project for the same two developers

## So what
- Lock frontend capacity before March (S→W1) and document analytics tagging in sprint one (W2).
- Time the launch to the search platform decision (O1) or the rebuild ships with legacy search.
